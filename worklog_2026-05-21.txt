-----------------------------------------------------------

reads entire PDF, supervises each stage as a gatekeeper
before pipeline proceeds to next step.

Actual implementation: Post-processing fallback at stage 9.5,
only triggers if count_recall < 95% (never happens) or Z=0.
Does NOT check XY positions. Does NOT read PDF. Does NOT
gate between stages.

Three-layer failure:
  1. Never triggers (accuracy=100% → skip)
  2. _verify_3d_positions() checks Z only, not XY clustering
  3. _apply_corrections() cannot update XY coordinates

ARR redesign required (Tier 2) — see plan file for details.

  File: agents/synthesizer_v7.py _is_structural_col() ~line 206
  Root cause: Synthesizer extracts WS1-H6.0-NOFRL, WS2-H5.5-60MIN
    etc. as structural columns. These are wall stud fire-resistance
    schedule table rows (WS = Wall Stud, H6.0 = height, 60MIN = FRL)
    not actual steel column instances. 22 phantom columns created,
    all with depth=5-6mm, all at fallback XY → scattered sticks
    visible in SketchUp screenshot (red circle area).
  Fix: Two guards added after _BP check:
    if re.match(r"^WS\d", mark_str):

        return False
  Result: columns 66 → ~44, phantom sticks eliminated

TIER 2C — PLAN PAGE COLUMN EXTRACTOR (new agent)
-----------------------------------------------------------

  New file: agents/plan_page_extractor.py
  Class: PlanPageColumnExtractor

  Purpose: Read all PLAN-type pages at 300 DPI via vision LLM,
    extract column_mark → grid position mapping.
    Feeds enrichment data into synthesizer to reduce fallback
    from 65% to <5%.

  run() method:
    1. Find PLAN page indices from scanner_output["page_results"]
    2. Open VisionRenderer at 300 DPI (vs 200 DPI for normal scan)
    3. For each PLAN page: render → call_llm with image → parse JSON
    4. Normalize all marks to uppercase for consistent lookup
    5. Return {MARK: {grid_label_x, grid_label_y, grid_x_mm, grid_y_mm}}

  _parse() method:
    Regex search for {...} in LLM response → json.loads → validate dict

  PromptFactory additions (pipelines/prompt_factory.py):
    system_prompt_plan_extractor(): senior structural detailer persona,
      JSON-only output format with example, strict rules (no guessing)
    user_prompt_plan_extract(page_idx): minimal, JSON-only instruction
    Registered as "plan_extractor" in build_full_system_prompt()

  Pipeline integration (pipelines/pipeline_v8.py):
    Added Stage 2.5 between scanner (Stage 2) and synthesizer (Stage 3)
    Wrapped in try/except — failure is non-fatal (plan_positions = {})
    Added plan_positions field to PipelineV8Result dataclass
    Stage 3 call updated: synthesize(scanner_output, plan_positions=plan_positions)

  Synthesizer enrichment (agents/synthesizer_v7.py):
    synthesize() signature updated: added plan_positions: dict = None
    Added _enrich_from_plan(model, plan_positions) method:
      For each column: lookup MARK.upper() in plan_positions
      If found: overwrite x_mm, y_mm, x, y, grid_x, grid_y
      Logs: [PLAN-ENRICH] N columns got grid position from plan pages
    Called in both LLM and deterministic paths after model assembly
