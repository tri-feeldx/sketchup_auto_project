PART 3: TIER 2 UPGRADES — CODED TODAY, AWAITING TEST
============================================================

After fixing all foundation bugs, started quality upgrades:

--- 3A: Teach the AI Australian steel standards (AS/NZS) ---

  Problem: AI occasionally confused connection hardware with
           structural steel columns.
  Fix:     Embedded the full AS/NZS 3678/3679 steel section
           catalogue into the AI prompt — like giving the AI
           a structural engineering textbook before it works.
  Expected: Fewer misclassifications structural vs hardware.

--- 3B: Confidence score for every element ---

  Each column, beam, and footing now gets a "_confidence"
  field (0.0 to 1.0) showing how certain the AI is about
  the spatial position of that element:
    1.0 = confirmed coordinates from drawing + grid label
    0.7 = has XY coordinates but no grid label
    0.4 = estimated position (fallback — likely wrong)

--- 3C: Spatial accuracy metric ---

  Before: System only counted "is the quantity correct?" 
          → could score 100% while positions are all wrong
  After:  Added spatial score measuring % of columns with
          reliable XY positions
  Grade A now requires BOTH:
    - Count recall >= 90%
    - Spatial score >= 75%

--- 3D: New agent — Plan Page Extractor ---

  This is the most impactful upgrade of the day.

  Problem: Currently 65% of columns use estimated (fallback)
           positions because the system was not reading the
           actual floor plan pages to extract true coordinates.
           Columns appear with correct shapes but wrong locations.

  Solution: Built a new AI agent that reads each floor plan
            page at high resolution (300 DPI), identifies
            every column mark, and records its exact position
            on the structural grid:
              Example: Column C1 → intersection of Grid A and Grid 1
                                 → coordinates (0mm, 7000mm)

  Expected result: Fallback drops from 65% → below 5%
                   3D model columns placed at correct positions


============================================================
PART 4: CURRENT PIPELINE WORKFLOW
============================================================

Any structural PDF goes through 9 automated stages:

  Stage 0-2:  Analyse + classify all 29 pages
              (SCHEDULE / PLAN / DETAIL / ELEVATION / FOUNDATION)

  Stage 2:    Scan 6 pages simultaneously, extract structural
              data from each page (~90-150 seconds)

  Stage 2.5:  [NEW] Read floor plan pages at 300 DPI
              → extract exact column grid positions

  Stage 3:    Synthesize into unified 3D model
              (AI knows AS/NZS standards, assigns confidence scores)

  Stage 4:    Cross-check element counts against schedules

  Stage 5:    Re-scan if any elements are missing (auto top-up)

  Stage 6:    Validate geometry (check dimensions are reasonable)

  Stage 7:    Generate Ruby script for SketchUp

  Stage 8:    Validate Ruby syntax

  Stage 9:    Score accuracy (count recall + spatial score)
              → Grade A / B / C

  Output:     .rb file → SketchUp 2026 → LOD300 3D model
